# CabMantra

CabMantra is a travel and pilgrimage services platform helping travelers
arrange cabs, hotels, puja services and VIP darshan across India.

## Travel Services

- Cab booking
- Outstation taxi services
- Hotel assistance
- Pujan services
- VIP Darshan
- Pilgrimage travel

## Popular Destinations

- Ujjain
- Varanasi
- Ayodhya
- Char Dham
- Vaishno Devi
- Tirupati
- Somnath
- Dwarka
